# The King Law Office, concept site

A concept website for The King Law Office, LLC, a criminal defense practice at 100 Bull St, Suite 200, Savannah, GA, which has no website of its own. Built as an agency portfolio demo. Not affiliated with the firm.

Run it (Windows Git Bash, Node 20+):

```
npm install && npm run build && npm start
```

Then open http://localhost:3003 (or http://<this PC's IP>:3003 from a phone on the same Wi-Fi).
